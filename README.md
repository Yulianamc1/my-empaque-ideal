# MY Empaque Ideal

Mini aplicación web independiente para orientar a clientas en la elección de plantillas de empaque.

## Características
- Sitio estático: HTML, CSS y JavaScript.
- Sin APIs, sin créditos y sin servicios de IA.
- Imágenes almacenadas localmente dentro del proyecto.
- Responsive para celular, tablet y computadora.
- Editable directamente desde `index.html`.

## Publicación
Puede desplegarse en Vercel como proyecto estático sin configuración adicional.
